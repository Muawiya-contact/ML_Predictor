USAGE NOTES
Use the six numbered main figures with the captions above. Figure 5 also has four individual PNG panels if the journal requires separate panels. PNG images are 300 dpi; PDF versions are vector exports. The report itself is SapBERT_Final_Paper_Report.pdf.

All plotted results come from saved measurements or fitted artifacts. No classifier was retrained while preparing this report. The embeddings are from the current dataset, which must not be described as independently verified clinical data. The original label-assignment rules and independent per-record review were not documented.

The 90.60% accuracy and 90.99% macro F1 measure agreement with supplied labels on previously examined test records. They are retrospective; fresh independent validation is needed. The study uses supplied/recovered clinical concepts; live Ollama translation accuracy is not established by these scores.

Only Logistic Regression is deployed. SapBERT weights remain frozen. Improved input representation and tuned preprocessing/classifier settings changed the complete pipeline; the classifier family did not change. Individual contributions of simultaneous changes have not been isolated experimentally.
