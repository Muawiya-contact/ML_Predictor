Serving flow

From Roman Urdu to a classifier input

  1. Collect the complaint and structured inputs. The GUI accepts Roman Urdu text, age, vital signs, gender, arrival mode, AVPU and ECG status. Substituted missing or unreadable structured values are disclosed.
  2. Normalize spelling. The fuzzy clinical dictionary corrects known Roman Urdu variants before translation. It also provides inspectable text stages.
  3. Translate locally. Ollama runs on localhost. The preferred model is llama3.2; the application reports the installed model actually selected. Requests use temperature 0.0 and few-shot examples.
  4. Apply translation guardrails. Refusal filtering removes unusable answers. A deterministic anatomical check requires named body parts to survive translation. Failed translations or anatomical mismatches receive no triage score.
  5. Preprocess English. Remove the active bundle's learned stop words. The English model has skip_normalization=true, so English text is not converted back through the Roman Urdu dictionary.
  6. Embed and combine features. MiniLM produces a 384-dimensional L2-normalized vector. Concatenate it after the 26 structured features.
  7. Classify and display. Logistic Regression produces class probabilities and triage level 1-4. The existing low-signal confidence cap and warnings remain part of scoring.

The six numeric inputs are age, heart rate, systolic and diastolic blood pressure, temperature and SpO2. Gender, arrival mode, AVPU and ECG status supply the categorical columns. The embedding block is not standardized again.

The manifest must declare structured features followed by embeddings. Model loading rejects unsupported layouts and checks the classifier input width. A missing bundle does not select a replacement classifier.

Evaluation

What the recorded scores measure

The active model was trained on 9 September 2026 using 2,252 synthetic cardiac records. The recorded stratified split contains 1,801 training rows and 451 test rows, seed 42.

These are the existing recorded results. The project cleanup retained the C classifier weights and did not rerun this experiment. Preprocessing reduced recorded under-triage by 0.66 points and accuracy by 0.22 points on this split.

Training translations were prepared using gpt-4o-mini; serving translates with Ollama. The classifier scores therefore do not measure the complete live translation workflow. Historical training also fits structured preprocessing before splitting and exports a full-data stop-word list beside a split-trained classifier. Those limitations belong in the research report.

Operator meaning

Confidence and safety checks

The displayed confidence is the winning class's probability, subject to the existing low-signal cap. It is not clinically calibrated. Anatomical consistency checks body-part preservation; it does not prove that every clinical detail or urgency cue survived translation.

The desktop exposes six tabs: Triage a Patient, Pipeline Explorer, Stop Words, Batch File, Results and Cluster Analysis. Batch output includes translation and gate verdicts. Rejected rows retain an explanation and no prediction.

The data is synthetic and the classifier is cardiac-only. The system is a research prototype, not a clinically validated medical device. Separate baseline and similarity studies cannot establish clinical reliability of its triage outputs.
